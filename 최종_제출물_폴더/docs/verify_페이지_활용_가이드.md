# verify.html 활용 가이드
## 1. 화면 목적

이 화면은 SIAP 수신 프레임의 원문, 필드 분해와 서버의 표준 준수 판정을 함께 확인하는 기능 데모다.
접속 주소는 `http://127.0.0.1:8000/verify.html`이다.
판정 근거는 TTAK.KO-10.0943 7.3.1 및 표 7-2·7-6·7-14를 따른다.

## 2. 화면 구성

- 왼쪽 위에는 골든 벡터 `X01`~`X08`과 1:1인 시나리오 주입 버튼이 있다.
- 프레임 목록은 정상, 위반, 알림 상태와 Node ID 및 수신 시각을 표시한다.
- `위반만 보기`는 표준 위반으로 판정된 프레임만 조회한다.
- `전체 알림 보기`는 위반이 아닌 NEC 알림도 목록에 포함한다.
- 노드 필터를 사용하면 특정 Node ID의 프레임만 확인할 수 있다.
- 오른쪽에는 선택 프레임의 원문 hex, 필드 분해와 판정 근거가 표시된다.

## 3. 시나리오 주입 절차

1. `1. Version 조작`부터 원하는 주입 버튼을 선택한다.
2. 주입 상태가 완료로 바뀌고 새 프레임이 목록에 나타나는지 확인한다.
3. 목록에서 해당 프레임을 선택해 원문 hex를 확인한다.
4. 필드 분해 항목을 선택해 비트 오프셋, 비트 폭과 원시값을 확인한다.
5. 판정 영역에서 코드명, 코드값, 0943 조항과 상세 사유를 확인한다.
6. 다른 벡터도 같은 방식으로 주입해 판정 결과를 비교한다.

## 4. 주입 벡터 해석

- `X01`~`X07`은 Version, Node ID, 길이, Message Type, Transmission Type, Value Type, Subtype 위반이다.
- `X08`은 NEC 배터리 저전력 알림이며 표준 위반이 아니므로 `알림`으로 표시된다.
- 화면은 판정 문자열을 자체 생성하지 않고 서버가 저장한 결과를 그대로 표시한다.
- 주입 바이트는 제출된 골든 벡터에서 읽으며 화면에서 임의 hex를 만들지 않는다.

## 5. 조회와 복사 기능

`hex 전체 복사`를 누르면 선택한 프레임 원문을 클립보드에 복사한다.
복사가 거부되면 브라우저의 클립보드 권한과 보안 컨텍스트를 확인한다.
필터를 변경하면 선택 상태가 바뀔 수 있으므로 판정할 프레임을 다시 선택한다.
새 프레임과 위반·알림은 SSE로 도착해 새로고침 없이 목록에 반영된다.

## 6. 시연 시 유의사항

주입은 운영 장치나 규칙 상태를 변경하지 않고 평소 수신 경로에 검증용 프레임을 넣는다.
프레임의 `정상`, `위반`, `알림`은 서로 다른 판정이므로 색상만으로 판단하지 말고 텍스트를 읽는다.
표준 위반 근거를 설명할 때는 원문 hex → 문제 필드 → 코드와 조항 순서로 제시한다.
실물 로그의 진위를 보존해야 하는 `hardware` 모드에서는 주입을 시도하지 않는다.

## 7. 완료 확인

- 선택 프레임의 hex와 필드 분해가 함께 표시된다.
- `X01`~`X07`은 위반, `X08`은 알림으로 구분된다.
- 위반 필터와 Node ID 필터가 목록에 반영된다.
- 판정 카드에 코드명, 코드값, 조항과 상세 사유가 표시된다.

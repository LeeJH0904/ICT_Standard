# index.html 활용 가이드
## 1. 화면 목적

이 화면은 등록된 노드·디바이스의 연결 상태, 최근 센서값, 구동기 상태와 알림을 한곳에서 조회하는 기능 데모다.
접속 주소는 `http://127.0.0.1:8000/index.html`이며 루트 주소 `http://127.0.0.1:8000/`로도 열린다.
화면 상단에는 TTAK.KO-10.0937 6.1·6.4와 TTAK.KO-10.0943 8.1.1 활용 근거가 표시된다.

## 2. 화면 구성

- 요약 바는 현재 노드 수, 디바이스 수, 알림 수를 표시한다.
- 노드 카드는 Node ID, 연결 상태, 소프트웨어 버전, 등록 상태와 디바이스 수를 보여준다.
- 센서 행은 최근값, 단위와 최근 10개 값의 추세 그래프를 표시한다.
- 구동기 행은 현재 속성과 서버가 제공한 유효 범위를 표시한다.
- 알림 영역은 심각도에 따라 아이콘과 색을 구분하고 발생 상대 시각을 보여준다.
- 표준 위반 프레임이 있으면 배너가 나타나며 상세 판정은 `verify.html`로 연결된다.

## 3. 기본 활용 절차

1. 상단 요약 바에서 예상한 노드·디바이스 수가 표시되는지 확인한다.
2. 각 노드 카드의 상태가 연결됨인지, 마지막 수신이 오래되지 않았는지 확인한다.
3. 센서 이름 옆 Subtype 코드와 최신 측정값·단위를 확인한다.
4. 작은 추세 그래프로 값의 상승·하락 또는 동일값 유지를 확인한다.
5. 구동기라면 현재 상태가 선언된 유효 범위 안인지 확인한다.
6. 알림 목록에서 `CRITICAL`, `WARN`, 일반 알림의 메시지와 시각을 확인한다.
7. 위반 배너가 나타나면 링크를 눌러 표준 준수 검증 화면에서 원문을 확인한다.

## 4. 실시간 갱신과 상태 해석

프레임 수신 시 SSE 이벤트를 통해 기존 노드의 값과 마지막 수신 시각이 자동 갱신된다.
짧은 시간에 프레임이 몰리면 화면은 갱신 요청을 묶어 처리하므로 순간 지연이 있을 수 있다.
새 노드 연결·해제 이벤트가 오면 노드와 디바이스 목록 전체를 다시 불러온다.
`아직 등록된 노드가 없습니다`는 오류가 아니라 조회 결과가 비어 있다는 뜻이다.
`불러오지 못했습니다`가 보이면 서버 실행 여부와 브라우저 주소를 먼저 확인한다.

## 5. 시연 시 유의사항

이 페이지는 조회 전용이며 규칙 승인, 제어 실행 또는 설정 변경을 수행하지 않는다.
위반의 조항·코드·필드 상세는 이 화면에서 추정하지 않고 서버 판정 결과를 `verify.html`에서 보여준다.
센서값과 상태는 서버 응답을 표시하므로 화면에서 임의 값을 만들어 증거로 사용하지 않는다.
심사 시에는 대시보드의 수량, 노드 카드, 센서 추세, 알림 순서로 설명하면 흐름이 명확하다.

## 6. 완료 확인

- 노드·디바이스·알림 수가 카드 및 목록과 일치한다.
- 센서와 구동기 표시가 장치 종류에 맞게 구분된다.
- 새 프레임 수신 후 새로고침 없이 값이 갱신된다.
- 위반 배너의 링크가 표준 준수 검증 화면으로 이동한다.

## 근거

`fix_log/README.md` — 인덱스는 하나이며 개별 파일은 해당 행의 상세다.

`bug_fix_list.md` 불변식 — 표준결함 행 수와 관련 문서 총계는 항상 일치해야 한다.

## 현상

다음 불일치가 동시에 존재한다.

- 실제 트리거는 31개인데 아키텍처 §8.2는 29개라고 한다.
- `CLAUDE.md` §3.6과 인덱스는 표준결함 17건이나 §9 참조표는 12건이다.
- F-022 인덱스 상태는 `수정완료`지만 상세 파일은 `신규`이고 Claude 처리 기록이 사라졌다.
- F-027 인덱스 심각도는 `치명`, 상세 파일은 `오류`다.
- F-026 처리 기록은 INT/UINT/FLOAT 실제 바이트 회귀 테스트를 추가했다고 하지만 현재 자동 검증 코드에는 해당 테스트가 없다.

## 영향

검증 인덱스·상세·설계 문서 중 무엇이 정본인지 다시 불명확해졌다. 통과 수치와 처리 완료 주장을 독립적으로 신뢰할 수 없고 같은 문제의 재발을 자동 검출하지 못한다.

## 제안

인덱스와 상세 헤더를 자동 대조하고, 표준결함 수·DDL 객체 수·실제 테스트 존재 여부를 검사하는 메타 검증을 둔다.

# F-045 · SIAP 검증기가 기본 한국어 Windows 콘솔에서 중단됨

| 항목 | 값 |
|---|---|
| 심각도 | 오류 |
| 분류 | 코드버그 |
| 대상 | `project_docs/siap/spec_verify.py:212` |
| 발견일 | 2026-08-03 |
| 상태 | 수정완료 |

## 근거

공고문 3장 「소스코드 제출 안내」 — "압축파일만으로도 실행 가능해야 함", "제출물만으로 실제 실행(재현)이 가능한 전체 소스코드"

F-013은 Windows 기본 환경에서 검증 스크립트가 실패하는 문제를 수정완료로 기록했다.

## 현상

F-044의 4차 검증 제목에 추가된 em dash(`—`, U+2014)를 `print()`한다. 한국어 Windows의 기본 Python 표준출력 인코딩이 CP949인 환경에서는 이 문자를 인코딩하지 못해 1~3차 검증 뒤 `UnicodeEncodeError`로 종료된다. `python -X utf8`에서는 통과하지만 기본 실행 명령에는 해당 옵션이 없다.

## 영향

제출물의 자체 검증 경로가 심사자 Windows 기본 환경에서 완료되지 않는다. F-013에서 해소한 재현성 결함이 새 출력 문자열 때문에 재발했다.

## 재현

```powershell
python -B project_docs/siap/spec_verify.py
# UnicodeEncodeError: 'cp949' codec can't encode character '\u2014'
```

## 제안

콘솔 출력은 CP949로 표현 가능한 문자만 사용하거나, 스크립트가 출력 인코딩을 명시적으로 재설정하도록 한다. 기본 Windows 실행을 회귀 테스트에 포함한다.

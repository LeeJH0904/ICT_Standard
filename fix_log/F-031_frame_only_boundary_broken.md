## 근거

Frame 구조 명세서 §1 — "계층 간에 오가는 것은 Frame 하나뿐이다"

아키텍처 §2 — `contracts/Frame`이 유일한 통행 타입이다.

## 현상

`SiapLink.registry()`는 `dict[int, NodeProperty]`, `devices()`는 `tuple[DeviceMainInfo, ...]`를 서비스 계층에 직접 반환한다. 두 타입은 0943 구조체를 표현하는 프로토콜 타입이며 Frame이 아니다.

## 영향

명시한 계층 경계가 계약 자체에서 깨지고 서비스 계층이 프로토콜 구조에 결합된다. 향후 구조체 변경이 backend까지 전파되며 "표준 해석은 한 곳"이라는 주장도 약해진다.

## 제안

해당 조회를 Frame 스트림/Frame 응답으로 통일하거나, Frame-only 원칙을 실제 의도에 맞게 "contracts 타입만 통과"로 정정하고 허용 타입 목록을 명시한다.

# F-066 · spec_examples 생성물이 정본보다 마지막 LF 1바이트 짧음

| 항목 | 값 |
|---|---|
| 심각도 | 오류 |
| 분류 | 코드버그 |
| 대상 | `project_docs/siap/spec_examples.json`, `project_docs/siap/spec_verify.py:329-342` |
| 발견일 | 2026-08-05 |
| 상태 | 수정완료 |

## 근거

공고문 「소스코드 제출 안내」 재현성(필수) — "서류 검증 단계에서 재현 불가 시 서면 평가에서 제외되므로 공모 접수 시 제출물만으로 실제 실행(재현)이 가능한 전체 소스코드를 제출해야 함."

F-063 처리 계약 — 생성기는 `--check`에서 아무것도 쓰지 않고 체크인된 생성물이 정본과 byte 단위로 같은지 판정한다.

## 현상

`spec_verify.py --check`가 만드는 기대 문자열은 길이 1,847자이며 마지막이 `]\n`이다. 체크인된 `spec_examples.json`은 길이 1,846자로 마지막 LF가 없어 첫 차이가 EOF(인덱스 1846)에서 발생한다.

그 결과 SIAP 검증이 종료코드 1, 전체 메타 검증이 33/34와 종료코드 1로 실패한다. 검증 전후 SHA-256은 같아 `--check`가 파일을 덮어쓰지는 않았다.

## 영향

골든 벡터 자체가 28/28이어도 제출물의 전체 검증 명령은 실패한다. 수정완료로 기록한 F-063의 회귀 기준을 현재 체크인 상태가 충족하지 못한다.

## 재현

```text
python -B project_docs/siap/spec_verify.py --check
→ FAIL spec_examples.json 이 생성 결과와 일치 (9건), exit 1

python -B fix_log/meta_verify.py
→ 33/34 통과, spec_verify.py 종료코드 0 항목 FAIL, exit 1
```

## 제안

정식 생성 명령으로 `spec_examples.json`을 한 번 재생성하고, `--check`와 메타 검증을 다시 실행한다.

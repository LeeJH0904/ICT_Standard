# F-198 · 기본 simulate 환경에서 웹 핵심 기능을 재현할 디바이스가 없음

## 근거

`CLAUDE.md` §7은 기본 검증 모드가 하드웨어 없이 재현 가능해야 한다고 정한다. TTAK.KO-10.0937 6.1은 장치 등록·연결, 6.4는 환경·장치 상태 모니터링, 6.5는 사용자 명령과 제어 결과 피드백을 요구한다.

## 현상

새 데이터베이스로 `run.py --mode simulate --serve`를 실행하면 노드 3, 102, 103, 104는 등록되지만 모든 `/nodes/{nodeId}/devices`, 텔레메트리, 장치 상태가 비어 있다. 대시보드는 `등록된 디바이스가 없습니다`만 표시하고, 규칙 화면의 승인·수동 제어 대상과 설정 화면의 대상 선택도 비어 있다.

## 영향

별도 하드웨어나 수작업 데이터 주입 없이는 단계 7 기능 1의 모니터링, 기능 3의 승인·제어 및 설정 흐름을 검증하거나 시연할 수 없다. 기본 재현 경로가 단계 출구의 실질 기능을 증명하지 못한다.

## 재현

임시 DB를 지정해 서버를 실행한 뒤 `/api/v1/nodes`에서 네 노드를 확인했다. 이어 각 `/api/v1/nodes/{nodeId}/devices`, `/api/v1/telemetry`, `/api/v1/device-states`가 모두 빈 결과임을 직접 조회했다. 검증 후 서버를 종료하고 임시 DB를 삭제했다.

## 근거

최종 README는 TTAK.KO-10.0937의 범위를 "클라우드 서비스 요구사항"으로 적고
구현 위치를 `backend/services/`로 제시한다. 같은 문서는 설계 문서와 요구사항 대조표가
최종 제출물에 포함되지 않는다고 명시한다.

## 현상

개발 대조표는 6.1-1, 6.2-3, 6.3-1·2·7·8을 부분 적용으로, 6.3-9와 FOS 다수를

없다. 구현 트리에는 EMS·DMS·MMS·FMS·FCS 다섯 서비스만 나열된다.

## 영향

개발 내부에서는 의도된 선택 적용이지만 최종 제출본만 보는 심사자는 세 번째 표준을
전체 구현했다고 해석할 수 있다. F-243~F-245의 구현 범위가 문서 주장 문제로 확대된다.

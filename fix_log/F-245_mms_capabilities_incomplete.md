## 근거

TTAK.KO-10.0937 6.3은 모델·알고리즘 등록 규약, 메타정보 등록·수정, 개발자 사용
가이드, 데이터 접근 인증·권한 설정, 개발자별·서비스별 호출 횟수·전송 용량 집계를
요구한다.

## 현상

MMS는 시드된 `control_model`의 조회·실행과 제어 규칙 초안 생성만 제공한다.
모델 등록·수정 API가 없고 `X-User-Id`는 코드 주석대로 인증이 아니라 DB 사용자
실재 확인이다. 개발자별·서비스별 사용량 집계 저장소와 경로도 없다.

`F-082`는 모델 등록·수정을 `⚠ 부분`으로, `F-052`는 자체 주장 헤더의 신원 한계를
기록했으나, 최종 제출 README에는 이 제한과 6.3-9 제외가 나타나지 않는다.

## 영향

시드 모델 실행 데모는 가능하지만 외부 개발자가 모델을 등록·관리하고 권한을 설정하며
사용량을 확인하는 표준 MMS 능력은 제공되지 않는다. 0937 전체 구현 표기가 과도하다.

## 재현

```powershell
rg -n '@app\.(post|patch|put|delete).*models|usage|bytes_sent' project_code/backend
# 모델 쓰기 API와 사용량 집계 경로 없음
rg -n '인증이 아니라' project_code/backend/repository.py
# X-User-Id는 실재 확인만 수행
```

## 제안

모델 등록·수정 API, 인증/인가, 호출·전송량 계측을 구현하거나 최종 README에서
`시드 모델 실행 및 승인 흐름만 적용`으로 범위를 제한한다.

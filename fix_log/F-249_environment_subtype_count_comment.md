## 근거

TTAK.KO-10.1369-Part1 6.3.3.1~6.3.3.11은 환경상태 데이터로 온도, 습도, 일사,
이산화탄소, 풍향, 풍속, 토양수분장력, 전기전도도, 수소이온농도, 감우 10종을 설명한다.
표준 자체의 그림 누락 문제는 `F-011` 표준결함으로 이미 이관됐다.

## 현상

`env_measurement`의 CHECK는 위 10종을 정확히 열거하지만 바로 앞 주석은
"그림 7-3의 9개 서브타입", "8종은 공통 구조"라고 적는다. 실제 CHECK 기준으로는
감우를 제외한 9종이 공통 구조다.

## 영향

실행 스키마는 올바르므로 현재 데이터 저장은 깨지지 않는다. 다만 표준 적용 범위를
코드 주석으로 추적하는 심사자와 유지보수자가 9종 구현으로 오인할 수 있다.

## 제안

본문 우선 결정에 맞춰 주석을 "10개 서브타입", "9종 공통 구조 + 감우"로 정정하고
`F-011`의 표준 그림 누락과 구분해 적는다.

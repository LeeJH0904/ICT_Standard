# F-067 · SIAP 구현 결정표에 폐기된 최대 51byte 근거가 남아 있음

| 항목 | 값 |
|---|---|

| 분류 | 문서불일치 |

| 발견일 | 2026-08-05 |
| 상태 | 수정완료 |

## 근거

0943 표 7-13 — `Num. of Devices`는 8bit이며 "노드에 연결된 디바이스 수"다.

0943 7.3.3.4 및 표 7-16 — "노드 속성과 해당 노드에 연결된 N개 디바이스의 속성 정보"를 포함하고 `DEVICE_PROPERTY` 길이는 `N*240`bit다.

## 현상

F-064 수정으로 아키텍처 §6.2-a는 표준 최대 프레임을 7,671byte, 구현 상한 N=16의 최대 프레임을 501byte로 바로잡고 기본 Timeout 2초를 그 산식에서 도출했다.

그러나 SIAP 명세서 §7 구현 결정표는 여전히 "9600 baud에서 최대 프레임 51byte ≈ 53ms이므로 최소 1초 해상도로 충분"하다고 적는다. 이는 F-064에서 폐기한 초안의 근거이며 같은 문서 §6-5c의 7,671byte 설명과도 모순이다.

## 영향

구현자가 SIAP 명세서만 따르면 최대 프레임과 Timeout 하한을 다시 51byte/1초 기준으로 되돌릴 수 있다. 정본 문서 사이에서 상한과 시간 근거가 둘로 갈린다.

## 제안

SIAP 구현 결정표도 N=16, 501byte, `Timeout >= 2 × wire_time` 및 기본 2초 결정으로 통일하고 아키텍처 §6.2-a를 연결한다.

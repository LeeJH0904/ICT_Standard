# settings.html 활용 가이드
## 1. 화면 목적

이 화면은 센서 디바이스 또는 온실 구역의 전송 모드와 수집 주기를 설정하는 기능 데모다.
접속 주소는 `http://127.0.0.1:8000/settings.html`이다.
TTAK.KO-10.0937 6.4-2·부속서 A 1.3과 TTAK.KO-10.0943 표 7-15를 활용한다.

## 2. 화면 구성

- `디바이스 개별`은 선택한 센서 설치 한 대에 설정을 적용한다.
- `구역 일괄 (온실)`은 조건에 맞는 여러 센서에 같은 설정을 적용한다.
- 구역 선택 조건은 온실 ID이며 위치와 Subtype 코드는 선택적으로 범위를 좁힌다.
- 전송 모드는 `PERIODIC`, `EVENT`, `BOTH` 중 하나를 선택한다.
- 수집 주기는 표 7-15의 14bit 범위인 0~16383초를 입력한다.
- 전송 모드와 수집 주기 중 최소 한 항목은 입력해야 한다.
- 전체 디바이스 목록은 현재 모드, 주기, 하한, 상한과 정밀도를 보여준다.

## 3. 디바이스 개별 설정

1. 대상에서 `디바이스 개별`을 선택한다.
2. 대상 장치 목록에서 설정할 센서를 선택한다.
3. 변경할 전송 모드 또는 수집 주기를 입력한다.
4. 바꾸지 않을 항목은 `변경 안 함` 또는 빈 값으로 둔다.
5. `적용`을 누르고 적용 대상 1대와 장치 이름이 상태 문구에 표시되는지 확인한다.
6. 아래 전체 디바이스 목록에서 새 설정값을 다시 확인한다.

## 4. 구역 일괄 설정

1. 대상에서 `구역 일괄 (온실)`을 선택한다.
2. 필수 온실 ID를 입력한다.
3. 필요하면 설치 위치와 0~255 범위의 Subtype 코드를 입력한다.
4. 적용할 전송 모드 또는 수집 주기를 입력한다.
5. `적용`을 누르기 전에 조건에 포함될 장치 범위를 확인한다.
6. 완료 문구의 대상 대수와 장치 이름을 확인하고 목록에서 결과를 검토한다.

## 5. 입력값과 결과 해석

`PERIODIC`은 주기 기반, `EVENT`는 이벤트 기반, `BOTH`는 두 방식을 함께 사용하는 설정이다.
수집 주기 `0`도 표의 허용 범위지만 장치 의미와 운영 정책을 확인한 뒤 사용한다.
구동기는 수집 설정 대상 선택 목록에서 제외되며 센서 디바이스가 주 대상이다.
서버가 반환한 대상이 0대라면 온실 ID, 위치와 Subtype 조건을 다시 확인한다.
적용 성공 후 화면은 전체 목록을 다시 조회하므로 저장된 최종값을 바로 확인할 수 있다.

## 6. 오류 대응과 유의사항

`설정값을 최소 1개 입력하세요`가 나오면 전송 모드나 수집 주기 중 하나를 입력한다.
범위 오류가 나오면 수집 주기가 0~16383인지, Subtype이 0~255인지 확인한다.
구역 일괄 설정은 여러 장치를 동시에 바꾸므로 조건을 넓게 지정하지 않도록 주의한다.
실제 장치 반영 여부까지 보이려면 양방향 응답을 제공하는 `simulate` 또는 적절한 `hardware` 환경을 사용한다.

## 7. 완료 확인

- 선택한 대상 방식과 실제 적용 대상이 일치한다.
- 변경하지 않은 속성은 기존 값으로 유지된다.
- 성공 문구의 대상 수와 디바이스 목록의 변경 결과가 일치한다.
- 새로고침 후에도 저장된 전송 모드와 수집 주기가 유지된다.

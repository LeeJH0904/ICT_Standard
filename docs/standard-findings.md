# 표준 실구현 장애 지점 — 19건

> CLAUDE.md §0 핵심 주장 4("표준의 실구현 장애 지점을 발견하고 해소했다")의 근거 문서.
> 정본은 `project_docs/siap/SIAP_메시지_명세서.md` §6(0943, 13건)과
> `project_docs/db/DB_스키마_설계서.md` §5(1369-Part1, 6건)이며, 이 문서는 그 둘을
> 제출용으로 통합한 것이다(CLAUDE.md §3.6). 각 항목의 F-ID는 `fix_log/bug_fix_list.md`
> "표준결함" 표의 해당 행과 1:1 대응한다 — 처리 이력·기각/보류 사유가 필요하면
> `fix_log/F-0xx_*.md` 개별 파일을 본다.
>
> 이 문서는 표준 원문을 재배포하지 않는다. 표·조항 번호로 위치만 가리키고, 불일치
> 내용과 본 구현의 처리(채택한 해석·결정)만 서술한다 — 원문은 `표준 문서 md 파일/`
> (제출물에서 제외, CLAUDE.md §2.1)에 있다.

## 2. TTAK.KO-10.1369-Part1 (데이터 요구사항) — 6건

1369-Part1을 스키마로 직역하는 과정에서 본문·개념모델·논리모델이 서로 어긋나는
지점을 확인했다.

| F-ID | # | 불일치 | 위치 | 채택한 해석 |
|---|---|---|---|---|
| F-010 | 1 | **온실정보·장치설치정보의 속성 구성이 그림마다 다르다.** 그림 7-2에는 소유자·관리자 속성이 없고 관계 엔티티(온실소유·온실관리)로만 표현되는데, 그림 7-4에는 `온실 정보`에 `관리자`·`소유자` 속성이, `장치설치 정보`에 `관리자`·`장치상태 데이터 식별자(FK)`가 직접 붙어 있다 | 그림 7-2 vs 그림 7-4 | 그림 7-2 + 본문 7.2.2를 정본으로 채택. 관계 엔티티가 규범 서술(7.2.2.7~10)에 명시되어 있으므로 FK 중복을 피했다 |
| F-011 | 2 | **환경상태 데이터 항목 수가 다르다.** 본문 6.3.3.1은 10종(온도·습도·CO2·일사·풍향·풍속·감우·토양수분장력·EC·pH)인데 그림 7-3에는 풍속이 없다(9종) | 6.3.3.1 vs 그림 7-3 | 본문 10종 채택. 풍속은 6.3.3.7에 독립 절이 있고 온실 환기 제어에 필요하다. 그림의 누락으로 판단 |
| F-012 | 3 | **장치상태 데이터 항목 수가 다르다.** 본문 6.3.4.1은 7종(창·보온덮개·차광막·환풍기·관수펌프·관수밸브·냉난방기)이라 하는데, 실제 절은 6개(6.3.4.2~6.3.4.7)이고 그림 7-3도 6종이다. 차광막만 항목 목록에 있고 정의가 없다 | 6.3.4.1 vs 6.3.4.2~7 / 그림 7-3 | 6종 채택. 차광막은 속성 정의가 없어 스키마화 불가. 확장 지점으로만 기록 |
| F-036 | 4 | **생육작물이 본문에만 있다.** 6.2.3은 "온실정보에는 … 난방형태, 생육작물, 작기정보, 활용상태 등이 포함되어야 한다"고 하는데, 그림 7-2·7-4의 `온실 정보`에는 작기정보만 있고 생육작물이 없다 | 6.2.3 vs 그림 7-2 / 7-4 | 본문 채택. `greenhouse_info.crop` 컬럼 추가 |
| F-037 | 5 | **감우의 단위 취급이 상반된다.** 본문 6.3.3.8은 "주로 사용하는 감우 데이터의 단위가 관리되어야 한다"를 요구하는데, 그림 7-3의 `감우`는 `측정값` 하나만 갖는다 | 6.3.3.8 vs 그림 7-3 | 본문 채택. 단위는 허용하고 오차범위·유효범위만 금지 |
| F-038 | 6 | **농장관리 관계가 논리적 모델에 없다.** 7.1(2)는 "농장 정보는 사용자 정보와 N:1 '농장 관리' 관계를 가진다"고 하는데, 7.2.2의 관계 엔티티 4종(온실소유·온실관리·장치설치·장치관리)에 농장관리가 없다 | 7.1(2) vs 7.2.2.7~10 | 논리적 모델 채택. 7.2.2.2가 `농장정보.소유자`를 FK로 규정하므로 `farm_info.owner_id`로 표현. 별도 관계 테이블은 두지 않음 |

> 본문 6.3.3.1은 `KS X 3269`, 6.3.4.1은 `KS X 3268`을 참고했다고 명시한다. 위
> 불일치는 두 KS 표준의 항목을 옮기는 과정에서 발생한 것으로 보인다.
